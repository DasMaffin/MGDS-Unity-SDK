# Changelog

## 0.1.0

- The MGDS Manager: one per game, kept across scenes, signs the player in when the game starts.
- Signing in: anonymous, Steam, dasmaffin.com; linking, signing out, the player's own data.
- Save files, with a one-call slot API.
- Leaderboards, remote config (with textures), reports (with logs, device info and screenshots),
  push messages (streamed, or long-polled on WebGL).
